# noya-cli 0.0.54

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **In lockstep with noyalib 0.0.54**: the exact core pin moves to `=0.0.54`, so this release picks up every core change for that version.
* **Atomic in-place writes**: `noyafmt --write` and `noyavalidate --fix` write a temporary file next to the target and rename it into place, keeping the file's permissions, so an interrupted run never leaves a truncated file.
* **`noyavalidate --strict`**: parse under the strict YAML 1.2 profile, where duplicate keys and odd indentation are errors and the tighter resource limits for untrusted input apply.
