# noya-cli 0.0.55

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **Safe in-place writes**: `noyafmt --write` and `noyavalidate --fix` create their temp file exclusively, under a random name and with the target's mode, before writing anything.
* **Several files, honest exit codes**: `noyavalidate` checks every file it is given and exits with the most severe code, so the pre-commit hooks work with more than one staged file. A schema that does not compile now fails. Rust API users: `NoyavalidateCli::file` is now `files: Vec<PathBuf>`.
* **Terminal-safe output**: control characters from files and file names print as U+FFFD, so a crafted file cannot drive the terminal or forge CI log lines. The GitHub Action validates every file under `paths` and checks its download.
* **In lockstep with noyalib 0.0.55**: the exact core pin moves to `=0.0.55`, so this release picks up every core change for that version, including limits enforced on every loader and linear-time parsing of long lines.
